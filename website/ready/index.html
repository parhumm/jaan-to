Current limits

Early testing means early testing.

  • Validated locally on macOS. Python and Node projects have first-class checks.
  • Passing checks reduce uncertainty. They cannot prove product correctness.
  • Real Claude and Codex runs remain disabled until provider safety validation passes.
  • No automatic model routing, merge, push, deploy, or publication.
  • Start with a disposable clone and review every result.

Short answers

Before you try it.

Is READY another coding model?

No. Claude Code or Codex proposes the patch. READY owns isolation, policy, workflow state, verification, evidence, and review delivery.

Can I switch between Claude and Codex?

Yes, between runs. You choose one enabled provider, model, and effort for a run. READY records that choice and does not silently switch midway.

Does READY guarantee the change is correct?

No. It proves that configured checks passed for the exact result. Good checks and human review still matter.

Does it edit my current checkout?

No. READY works in its own Git worktree. After review, you can export a patch or keep a result branch.

Can I use my existing subscriptions?

READY is designed to accept supported ChatGPT and Claude subscription logins only. It rejects API and pay-as-you-go identities. Real-provider use remains gated during early testing.
